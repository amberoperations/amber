Privacy policy

Amber, a private self-hosted personal assistant. Last updated 5 October 2026.

Who uses Amber

Amber is used by a single person, its owner, for personal purposes. It is not offered to the public and has no other users.

What Google data Amber accesses

With the owner's consent, Amber accesses the assistant's own Google account:

  • Gmail: reads, labels, drafts and sends email, so the owner can give Amber instructions by email and receive replies and briefings.
  • Google Calendar: reads events and creates or accepts events.
  • Google Drive: read-only access to files the owner asks about.

How the data is used and stored

  • Data is processed on the owner's private home server. OAuth tokens are stored there with access restricted to that server.
  • To answer the owner's requests, relevant content may be sent to Anthropic's Claude API for processing, and replies are delivered to the owner via Telegram.
  • Google data is used only to provide Amber's features to its owner. It is not sold, not used for advertising, and not shared with anyone else.

Google API Services User Data Policy

Amber's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Stored tokens are then useless and are deleted from the server.
